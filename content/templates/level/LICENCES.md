# Licences

Every file in this project and where it comes from. A game build refuses a file with no row here, so add one for
every file you put in (a table row: the file's path in backticks, then its licence; `*` matches within one folder).

"Xocialize original" means made for VRMXG by Xocialize LLC and released under CC0 1.0: use, change and ship it in your
game with no credit needed.
